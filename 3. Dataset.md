## Dataset

The PubMed dataset is a citation network of medical research papers where:
- Nodes represent scientific (biomedical) papers  
- Edges represent citation links between papers  
- Node features are bag-of-words representations of paper content  

Statistics:
- ~19,717 nodes  
- ~44,338 edges  
- 500 features per node  

This dataset is large and structurally rich, with fewer features compared to smaller benchmarks. As a result, learning is driven more by graph structure than feature similarity, making it well-suited for studying robustness in link prediction.
